# UI Refactor Guide — AI Invoice Processing System

## Objective
Replace the current raw Tailwind CSS UI with a professional, modular component system using **shadcn/ui** + **Lucide React icons** + **Tailwind CSS v3**.

## Tech Stack
| Layer | Technology | Version |
|-------|-----------|---------|
| Framework | Next.js (App Router) | 16.x |
| Runtime | React | 19.x |
| Language | TypeScript | 5.9 |
| Styling | Tailwind CSS | 3.4 |
| Component Library | shadcn/ui (Radix primitives) | latest |
| Icons | Lucide React | latest |
| Fonts | Geist Sans / Geist Mono (local) | — |

## Architecture Decisions

### 1. Component Library: shadcn/ui
- **Why**: Copy-paste component system, not a dependency — full ownership of code
- **Primitives**: Based on Radix UI — accessible, composable, unstyled base
- **Location**: `src/components/ui/` (auto-generated by CLI)
- **Customization**: CSS variables in `globals.css`, full Tailwind class control

### 2. Icons: Lucide React
- **Why**: Tree-shakeable, consistent 24x24 SVG icons, shadcn/ui default
- **Replaces**: All emoji icons (📊💬📄📦🏢📤🖼️) and inline SVGs
- **Usage**: `import { LayoutDashboard } from "lucide-react"`

### 3. Sidebar: shadcn/ui Sidebar
- **Why**: Built-in responsive behavior, collapsible modes, accessibility
- **Variant**: `sidebar` with `offcanvas` collapsible for mobile
- **Replaces**: Custom Sidebar.tsx with manual mobile drawer logic

## Color System (CSS Variables in globals.css)
shadcn/ui uses HSL-based CSS variables for theming:
- `--background`, `--foreground` — page background/text
- `--card`, `--card-foreground` — card surfaces
- `--primary`, `--primary-foreground` — primary actions (blue-600 equivalent)
- `--destructive` — delete/error actions
- `--muted`, `--accent` — secondary surfaces
- `--border`, `--ring` — borders and focus rings

## Rules
1. **Do NOT downgrade packages** — use latest compatible versions
2. **Do NOT use old patterns** — no raw `className` strings for common UI elements
3. **Do NOT edit files in `src/components/ui/`** — these are generated by shadcn CLI
4. **DO use the shadcn `cn()` utility** for conditional classes
5. **DO keep all existing functionality** — this is a visual refactor only
6. **DO preserve mobile responsiveness** — test all breakpoints
7. **DO use semantic HTML** through shadcn components (DialogTitle, TableHeader, etc.)

## Execution Order
1. Install dependencies: `lucide-react`, `class-variance-authority`, `clsx`, `tailwind-merge`
2. Run `npx shadcn@latest init` (style: default, colors: slate, CSS variables: yes)
3. Add components: `npx shadcn@latest add button card table badge input select dialog alert textarea label separator skeleton tooltip sidebar`
4. Create `app-sidebar.tsx` with Lucide icons and shadcn Sidebar primitives
5. Update `layout.tsx` with SidebarProvider/SidebarInset
6. Update `globals.css` with shadcn CSS variables
7. Refactor each page: Dashboard → Products → Suppliers → Invoices → Chat
8. Verify build passes: `npm run build`
